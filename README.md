# postal-code-search-in-browser
ブラウザで郵便番号検索

# リンク

記事: https://zenn.dev/dameyodamedame/articles/fa6fca97e12ea9

デモ画面: https://marudedameo2019.github.io/postal-code-search-in-browser/

# デモ画面のビルド方法

```sh
$ git clone https://github.com/marudedameo2019/postal-code-search-in-browser.git
$ cd postal-code-search-in-browser.git
$ npm i
$ npm run build
$ npm run generate
```

# デモ画面の動かし方

このディレクトリで`npx http-server`や`npx serve .`などを実行
